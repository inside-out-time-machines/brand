# Jottem merkgids

De huisstijl van het [Jottem](https://www.iotm.nl/)-platform (Inside Out Time Machines):
merkverhaal en tone of voice, logo met alle varianten, kleurenpalet, typografie
(Fraunces + Albert Sans, lokaal gehost), vormtaal, beeldgebruik en motion-principes —
met downloadbaar logopack, fontpakket en CSS-tokens.

- Live: https://brand.iotm.nl/
- Ontwerpdocument: https://github.com/inside-out-time-machines/design
